# Gestión y Reserva de Canarios

Aplicación web desarrollada como Proyecto Intermodular para 2º de DAW. Está pensada para criadores de canarios y aficionados a la ornitología deportiva.

## Problema que resuelve

En plena temporada de cría es habitual que se muera un ejemplar o falle una pareja reproductora, lo que obliga a buscar un sustituto con urgencia. Actualmente esto se hace mediante mensajes desordenados en grupos de WhatsApp, provocando malentendidos, pérdida de tiempo y ejemplares apabullados o pedidos por varios criadores a la vez.

La plataforma centraliza la oferta de ejemplares disponibles y soluciona el problema de los solapamientos bloqueando el pájaro en el momento exacto en el que alguien solicita su reserva.

## Funcionalidades principales

* **Registro de criadores:** Acceso seguro con cuenta individual para cada aviario.
* **Catálogo federado:** Publicación de ejemplares indicando número de anilla federada, raza, sexo y año de nacimiento.
* **Buscador con filtros:** Búsqueda rápida por sexo, gama o año para encontrar sustitutos al instante.
* **Sistema de reservas con bloqueo:** Bloqueo automático e inmediato del canario para evitar reservas dobles simultáneas.
* **Panel de gestión:** Vista para que el criador oferente acepte o rechace solicitudes, y el solicitante compruebe el estado de sus reservas.
